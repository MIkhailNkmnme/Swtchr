Swtchr — переключатель раскладки для Windows
=============================================

Исправляет текст, набранный не в той раскладке: «ghbdtn» → «привет», «руддщ» → «hello».
Аналог Punto Switcher / dotSwitcher. Один файл исходного кода, без установки и без
сторонних библиотек. Работает только с русской и английской раскладками.


ВОЗМОЖНОСТИ
-----------

1. Клавиша-триггер (по умолчанию левый Shift, удобно — Ctrl+Shift)
   Нажать и отпустить, ничего другого не нажимая:
     • есть выделение      → перебивается выделенный текст, выделение остаётся
                             (повторное нажатие перебивает обратно);
     • первое нажатие      → последнее набранное слово;
     • второе подряд       → вся строка (набранное с последнего Enter / клика);
     • третье подряд       → всё обратно, как было.
   «Подряд» — если между нажатиями ничего не набирали и не кликали.
   Если после клика ничего не набрано — берётся слово перед курсором / строка через выделение.

2. Автопереключение (auto_switch=1)
   Слово, набранное не в той раскладке, перебивается само — прямо на ходу, после 3–5 букв,
   или на пробеле. Раскладка переключается, дальше печатаете уже правильно.
   Словари не используются: программа сравнивает, на что набранное больше похоже —
   на слово своего языка или на слово в другой раскладке. Для этого внутри есть таблицы
   частот троек букв для русского и английского (собраны из строк интерфейса Windows).
   Короткие слова из 2–3 букв («не», «по», «что», «the», «to»…) — по встроенному списку.
   Не трогает: код и имена (getValue, iPhone), аббревиатуры (SQL, API), слова с цифрами,
   @, / и т.п., консоли.
   Ошиблось — сразу нажмите клавишу-триггер: слово вернётся и запишется в Swtchr.ignore.txt,
   больше само перебиваться не будет.

3. Перебивка двойным пробелом (space_switch=1)
   После слова уже стоит пробел, и вы жмёте пробел ещё раз:
     • второй пробел   → перебивается последнее слово (лишний пробел не остаётся);
     • третий          → вся строка;
     • четвёртый       → всё обратно.
   Включается либо автопереключение, либо двойной пробел — не оба сразу.

Работа в RDP: в окне RDP-клиента (mstsc / msrdc) Swtchr ничего не делает (ignore_rdp=1) —
на удалённой машине запускается свой Swtchr, иначе слово перебьётся дважды.


УСТАНОВКА И СБОРКА
------------------

Компилятор C# входит в Windows (.NET Framework 4), ставить ничего не нужно:

    build.cmd

Получится Swtchr.exe. Запустить — в трее появится значок «Яz».
Автозапуск с Windows включается в настройках.


НАСТРОЙКИ
---------

Правый клик по значку в трее → «Настройки…» (или двойной клик по значку).
В трее же — быстрые переключатели «Автопереключение» и «Перебивка двойным пробелом».

Всё хранится в Swtchr.ini рядом с exe (создаётся при первом запуске):

    key=Ctrl+Shift       клавиша-триггер: LShift RShift Shift LCtrl RCtrl Ctrl
                         LAlt RAlt Alt LWin RWin Win, сочетание — через «+»
    switch_layout=1      переключать системную раскладку после перебивки
    ignore_rdp=1         не работать в окне RDP-клиента
    auto_switch=1        автопереключение
    space_switch=0       перебивка двойным пробелом
    debug=0              1 — журнал в Swtchr.log (для отладки; галочка в настройках)

Если правите файл руками — перезапустите Swtchr.

Замечания:
  • Если в Windows раскладка тоже переключается по Ctrl+Shift, при срабатывании она
    переключится дважды. Уберите это сочетание в Windows (Параметры → Время и язык →
    Ввод → Дополнительные параметры клавиатуры → Сочетания клавиш для языков ввода)
    или выключите «Переключать раскладку после конверсии».
  • Автопереключение не отличает поле пароля от обычного текста. Если пароль похож на
    слово в другой раскладке — выключите автопереключение в трее на время ввода.
  • Двойной пробел, поставленный нарочно, при space_switch=1 тоже перебьёт слово.


ФАЙЛЫ
-----

    Swtchr.cs            исходный код (всё в одном файле, включая таблицы троек букв)
    build.cmd            сборка
    Swtchr.ini           настройки (создаётся сам)
    Swtchr.ignore.txt    слова, которые вы отменили после автоперебивки (создаётся сам)
    Swtchr.log           журнал при debug=1


КАК ЭТО УСТРОЕНО
----------------

  • Низкоуровневый хук клавиатуры и мыши (SetWindowsHookEx) следит за набором; набранное
    с последнего Enter / клика / смены окна хранится в буфере.
  • Перебивка набранного — Backspace нужное число раз и повторный ввод тех же клавиш
    уже в другой раскладке (как dotSwitcher). Unicode-ввод — только запасной путь:
    часть приложений и RDP превращают его в мусор.
  • Перебивка выделения — через буфер обмена (Ctrl+C / Ctrl+V); прежний текст буфера
    возвращается через 300 мс.
  • Выделение программа определяет по косвенным признакам: протяжка или двойной клик
    мышью, Shift+стрелки/Home/End, Ctrl+A.
  • Автопереключение — средний log P(буква | две предыдущие) для слова «как есть» и для
    слова «в другой раскладке»; перебивается, если второе заметно правдоподобнее.
    Чем меньше набрано букв, тем строже порог. Проверка на 5 тыс. отложенных слов:
    ~0,2% ложных срабатываний, ловится ~94% слов не в той раскладке.
  • Сетью программа не пользуется: ничего никуда не отправляет.
