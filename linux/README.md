# Swtchr для Debian XFCE / X11 — первый прототип

Отдельная Linux-ветка проекта. Windows-версия в `main` не затронута.

## Подготовка

Сеанс должен быть X11: `echo $XDG_SESSION_TYPE` → `x11`.

Установить зависимости:

```bash
sudo apt update
sudo apt install -y python3-xlib xdotool xclip git
```

## Запуск

```bash
git clone --branch linux --single-branch https://github.com/MIkhailNkmnme/Swtchr.git
cd Swtchr
python3 linux/swtchr_x11.py
```

Для остановки нажать `Ctrl+C` в терминале, где запущена программа.

Проверка таблицы преобразования без перехвата клавиатуры:

```bash
python3 linux/swtchr_x11.py --convert ghbdtn
```

Результат: `привет`.

## Возможности этой версии

- `Ctrl+Shift` (нажать и отпустить без других клавиш): исправить последнее слово слева от курсора.
- Каждое последующее нажатие расширяет исправление на **одно слово влево**, не изменяя уже исправленные слова.
- Когда исправлен текст до начала строки, следующее нажатие восстанавливает первоначальную строку.
- Работает посредством X11 RECORD, X11 PRIMARY selection и `xdotool`.
- Не использует сеть и не сохраняет введённый текст в файлы.

## Ограничения и безопасность

**Это экспериментальный прототип, а не полноценный перенос версии для Windows.** Проверяй сначала в обычном редакторе с неважным текстом, например Mousepad. Особенно осторожно с несохранёнными документами.

- Автоматической коррекции, исправления по двойному пробелу, настроек через трей, поддержки выделенного текста и автозапуска пока нет.
- Терминалы намеренно исключены из коррекции.
- Не использовать для паролей или конфиденциальных данных. Глобальный X11-перехватчик в текущем варианте видит события нажатий для отслеживания сочетания, хотя не сохраняет их и не отправляет.
- X11 PRIMARY selection и обработка клавиш отличаются между программами; в некоторых полях ввод может вести себя иначе либо не сработать.
- В этой версии программа **не переключает системную раскладку автоматически**.
- Если `Ctrl+Shift` в XFCE уже переключает раскладку, отключи это сочетание в настройках клавиатуры, иначе возможен конфликт.
- Для остановки в другом терминале: `pkill -f 'python3 linux/swtchr_x11.py'` (только если сам запускал этот скрипт).
- Прототип пока не проходил проверку в реальной пользовательской сессии XFCE/X11 на твоём неттопе.

## Дальнейшие шаги

Добавить надёжную обработку выделения, переключение раскладки, отмену, безопасную фильтрацию полей и затем автокоррекцию по статистическим моделям из `Swtchr.cs`. Все функции требуют отдельных испытаний в XFCE.

## Обновление и повторный запуск

Останови старый Swtchr сочетанием `Ctrl+C` в терминале, где он запущен, и выполни:

```bash
cd ~/Swtchr
git pull --ff-only
python3 linux/swtchr_x11.py
```

### Если появляется «Залипание клавиш»

Открой `xfce4-accessibility-settings` и на вкладке «Клавиатура» отключи «Залипание клавиш» и автоматическое включение специальных возможностей клавишами (если оно включено). Также проверь, что `Ctrl+Shift` не назначено в XFCE для переключения раскладки.
